# APCM COMPLETE VIDEO PLACEMENT PLAN

## Homepage hero: use ONE video only
Use a 8-15 second, muted, looped campus/infrastructure video.
Recommended sequence:
1. Main entrance / college identity
2. Campus buildings
3. Students walking / learning
4. Laboratory / library
5. End on a clean campus shot

Overlay:
A.P.C. MAHALAXMI COLLEGE FOR WOMEN
Empowering students with quality education and moral values
[ APPLY NOW ] [ EXPLORE PROGRAMMES ]

Do NOT put multiple autoplay videos on the homepage.

## Placement / Career
Use a short official placement/training video when supplied.
Otherwise use event photos and placement statistics. Do not use a generic stock "corporate" video.

## Gallery
Do not autoplay. Use click-to-play video cards with thumbnails.

## Technical rules
Hero video:
- MP4 H.264
- 1920x1080
- 8-15 sec
- muted
- autoplay
- loop
- playsinline
- poster image required
- compressed for web

YouTube videos:
- embed using youtube-nocookie.com
- click-to-play preferred
- use the official YouTube video rather than copying the MP4 unless the college has rights to the file.
